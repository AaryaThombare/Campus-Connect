# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple Bash-based application that calculates simple interest based on user input.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input Details
- Principal: Initial amount of money.
- Rate: Annual rate of interest.
- Time: Time period in years.

## Features
- Accepts principal amount from the user.
- Accepts rate of interest.
- Accepts time period.
- Calculates simple interest.
- Displays the total amount.

## Technologies Used
- Bash Shell Scripting
- Git
- GitHub

## How to Run
Execute the following command in the terminal:

```bash
bash simple-interest.sh
```

## Example

Input:
- Principal: 1000
- Rate: 5
- Time: 2

Output:
- Simple Interest: 100
- Total Amount: 1100
